# Cuenca phone test (prototype)

Static build of the phone speed test of a 3D river view: the Paraguay River from Confluencia to Asunción. Built from `models/T1-01_phone_test` in the private research repo.

Open data only: elevation from AWS Terrain Tiles (Mapzen/Tilezen; USGS SRTM, GMTED2010); river from Natural Earth. Libraries: CesiumJS, MapLibre GL JS.
